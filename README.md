## สำหรับพนักงาน

### เข้าใช้ครั้งแรก
1. เปิดลิงก์ระบบใน **Chrome** หรือ **Safari**
   ถ้าเปิดจาก LINE ให้กด ⋯ มุมขวาบน แล้วเลือก **เปิดในเบราว์เซอร์** เพราะ Google ไม่อนุญาตให้เข้าสู่ระบบจากในแอป LINE
2. กด **เข้าสู่ระบบด้วย Google** ด้วย Gmail ของตัวเอง
3. กรอก **ชื่อ นามสกุล** และเลือก **ทีม** แล้วกด **เริ่มใช้งาน** (ทำครั้งเดียว)

แนะนำให้เพิ่มลิงก์ไว้ที่หน้าจอโฮมของโทรศัพท์ (Add to Home Screen)

### ยื่นใบลา
1. แท็บ **ลางาน** › หัวข้อ **ยื่นใบลา**
2. เลือกประเภทการลา วันที่เริ่ม และวันที่สิ้นสุด ติ๊ก **ลาครึ่งวัน** ได้ถ้าลาวันเดียว
3. ระบบจะบอกทันทีว่านับกี่วัน ได้ค่าจ้างกี่วัน และเกินสิทธิ์หรือไม่
4. ใส่เหตุผล แล้วกด **ส่งใบลา**

### ติดตามใบลา
- **สิทธิ์การลาปีนี้:** ด้านบนของแท็บลางาน แสดงจำนวนวันที่ใช้ไปและที่เหลือของแต่ละประเภท
- **ใบลาของฉัน:** แสดงสถานะ **รออนุมัติ · อนุมัติแล้ว · ไม่อนุมัติ** และชื่อผู้พิจารณา
- **ยกเลิกใบลา:** ทำได้เฉพาะใบที่ยังรออนุมัติ กด **ยกเลิก** แล้วกดยืนยัน

### สิ่งที่พนักงานทำไม่ได้
ดูข้อมูลของคนอื่น อนุมัติใบลาเอง แก้ชื่อหรือย้ายทีมเอง (ติดต่อผู้ดูแล)

## สำหรับผู้ดูแล

ผู้ดูแลเห็นแท็บเพิ่ม: **รายงานการลา · อนุมัติการลา · พนักงาน · ตั้งค่า**

| แท็บ | ใช้ทำอะไร |
|---|---|
| **อนุมัติการลา** | อนุมัติหรือไม่อนุมัติใบลา ใส่ข้อความถึงพนักงานได้ เห็นสิทธิ์คงเหลือและวันที่ได้หรือไม่ได้ค่าจ้าง ตัวเลขแดงบนแท็บคือจำนวนใบที่รออยู่ |
| **รายงานการลา** | วันลารายเดือนของแต่ละคน แยกตามประเภท พร้อมยอดที่ไม่ได้ค่าจ้างและยอดทั้งปี กรองตามทีม ย้อนดูเดือนก่อน และกด **ส่งออก CSV** เพื่อเปิดใน Excel |
| **พนักงาน** | รายชื่อทุกคนที่ลงทะเบียน ค้นหาได้ กด **แก้ไข** เพื่อแก้ชื่อ ย้ายทีม กำหนดวันทำงานรายคน หรือนำออกจากรายชื่อ |
| **ตั้งค่า** | เปิด-ปิดการลงเวลา วันทำงาน วันหยุดบริษัท สิทธิ์การลา และรายชื่อผู้ดูแล |

### งานที่ทำครั้งแรก
1. **ตั้งค่า › เวลางาน:** เลือกวันทำงาน (ใช้นับจำนวนวันลา)
2. **ตั้งค่า › วันหยุดบริษัท:** ใส่บรรทัดละวัน รูปแบบ ปี ค.ศ.
   ```
   2026-12-07 วันหยุดชดเชยวันพ่อแห่งชาติ
   2026-12-10 วันรัฐธรรมนูญ
   2026-12-31 วันสิ้นปี
   ```
3. **ตั้งค่า › สิทธิ์การลา:** ปรับให้ตรงกับสัญญาจ้าง ถ้าต่างจากค่าเริ่มต้น
4. กด **บันทึกการตั้งค่า**

### เพิ่มผู้ดูแล
**ตั้งค่า › ผู้ดูแลระบบ** › ใส่ Gmail › **เพิ่มผู้ดูแล** ผู้ดูแลทุกคนมีสิทธิ์เท่ากัน
เจ้าของ Google Sheet และ Apps Script เป็นผู้ดูแลหลักเสมอ และถูกนำออกจากหน้านี้ไม่ได้

### เปิดใช้การลงเวลาเข้า-ออกงาน
**ตั้งค่า** › ติ๊ก **เปิดใช้การลงเวลาเข้า-ออกงาน** › **บันทึกการตั้งค่า**
จะมีแท็บ **ลงเวลา** (พนักงาน) และ **วันนี้ · รายงานรายเดือน** (ผู้ดูแล) เพิ่มขึ้นทันที ไม่ต้องแก้โค้ด
- เวลาเข้า-ออกงานใช้เวลาของเซิร์ฟเวอร์ แก้นาฬิกาโทรศัพท์ก็โกงไม่ได้
- คำนวณมาสาย โอที ขาดงาน และชั่วโมงทำงานให้อัตโนมัติ
- กำหนดเวลาเข้า-เลิกงานรายคนได้ในแท็บ **พนักงาน** รองรับกะข้ามคืน
- ผู้ดูแลแก้เวลาที่ลืมลงได้ ระบบบันทึกว่าใครแก้

### ลบใบลา
ยังไม่มีปุ่มลบในหน้าเว็บ ลบได้ที่ Google Sheet แท็บ **ใบลา** › คลิกขวาที่เลขแถว › **ลบแถว**
ถ้าต้องการเก็บประวัติไว้ ให้กด **ไม่อนุมัติ** แทน ใบลานั้นจะไม่ถูกนับในรายงาน

## ประเภทการลา

ค่าเริ่มต้นตาม พ.ร.บ.คุ้มครองแรงงาน รวมฉบับที่ 9 พ.ศ. 2568 ผู้ดูแลปรับได้ในแท็บ **ตั้งค่า**

| ประเภท | มาตรา | ลาได้ | ได้ค่าจ้าง | นับวัน |
|---|---|---|---|---|
| ลาป่วย | 32, 57 | ตามที่ป่วยจริง | ไม่เกิน 30 วัน/ปี | วันทำงาน |
| ลาทำหมัน | 33, 57 | ตามที่แพทย์กำหนด | ทุกวันที่ลา | วันทำงาน |
| ลาคลอด | 41, 59 | ไม่เกิน 120 วัน/ครรภ์ | ไม่เกิน 60 วัน | รวมวันหยุด |
| ลาดูแลบุตรเจ็บป่วย/พิการ | ฉบับที่ 9 | ไม่เกิน 15 วัน/ครั้ง | 50% | รวมวันหยุด |
| ลาช่วยเหลือภริยาคลอดบุตร | ฉบับที่ 9 | ไม่เกิน 15 วัน/ครั้ง | ทุกวันที่ลา | วันทำงาน |
| ลากิจธุระอันจำเป็น | 34, 57/1 | ไม่น้อยกว่า 3 วัน/ปี | ไม่เกิน 3 วัน/ปี | วันทำงาน |
| ลารับราชการทหาร | 35, 58 | ตามที่ถูกเรียก | ไม่เกิน 60 วัน/ปี | วันทำงาน |
| ลาพักร้อน | 30, 56 | ไม่น้อยกว่า 6 วัน/ปี | ทุกวันที่ลา | วันทำงาน |
| ลาอื่นๆ | – | ตามการอนุมัติ | ไม่ได้ค่าจ้าง | วันทำงาน |

ระบบแบ่งวันได้ค่าจ้างและไม่ได้ค่าจ้างให้อัตโนมัติ เช่น ลาป่วยวันที่ 31 ของปีเป็นต้นไปนับเป็นไม่ได้ค่าจ้าง

> ผู้รับจ้างเหมาบริการของหน่วยงานรัฐอาจมีสิทธิ์การลาตามสัญญาจ้างหรือระเบียบของหน่วยงาน ซึ่งอาจต่างจากกฎหมายแรงงาน ควรตรวจสอบกับสัญญาจ้างแล้วปรับค่าในแท็บตั้งค่าให้ตรงกัน

## ระบบทำงานอย่างไร

```
ผู้ใช้ ──► หน้าเว็บ (GitHub Pages) ──► Google Apps Script ──► Google Sheet
           เข้าสู่ระบบด้วย Google      ตรวจตัวตนกับ Google        เก็บข้อมูลทั้งหมด
                                   ตรวจสิทธิ์ผู้ดูแล
```

- **ข้อมูลทั้งหมดอยู่ใน Google Sheet ของเจ้าของระบบ** ไม่ได้อยู่ใน GitHub พนักงานไม่ต้องและไม่ควรได้สิทธิ์เปิดชีต
- ทุกคำขอต้องมีการเข้าสู่ระบบ Google ที่ถูกต้อง Apps Script ตรวจกับ Google ทุกครั้ง
- ค่าใน `config.js` (ลิงก์ Apps Script และ Client ID) ไม่ใช่รหัสลับ เปิดเผยได้
- **ใช้ฟรีทั้งหมด:** Google Sheet, Apps Script, Google Sign-In และ GitHub Pages ไม่มีค่าใช้จ่าย ถ้าใช้งานเกินโควตาฟรีรายวัน ระบบจะหยุดชั่วคราวจนถึงวันถัดไป ไม่มีการเรียกเก็บเงิน

### ไฟล์

| ไฟล์ | อยู่ที่ไหน | หน้าที่ |
|---|---|---|
| `index.html` | GitHub (repository นี้) | หน้าเว็บทั้งหมด |
| `config.js` | GitHub (repository นี้) | ลิงก์ Apps Script และ Client ID |
| `Code.gs` | Apps Script ใน Google Sheet | ระบบหลังบ้าน ตรวจตัวตน อ่าน-เขียนชีต |

### ข้อมูลใน Google Sheet

| แท็บ | เนื้อหา |
|---|---|
| `พนักงาน` | อีเมล ชื่อ นามสกุล ทีม เวลางานรายคน (ว่าง = ใช้ค่ามาตรฐาน) |
| `ใบลา` | ใบลาทั้งหมด สถานะ ผู้อนุมัติ และวันที่พิจารณา |
| `ตั้งค่า` | ค่าจากแท็บตั้งค่าในหน้าเว็บ และรายชื่อผู้ดูแล |
| `ลงเวลา_2026`, `ลงเวลา_2027`, … | เวลาเข้า-ออกงาน หนึ่งแถวต่อคนต่อวัน (เมื่อเปิดใช้การลงเวลา) |

⚠️ **ห้ามเปลี่ยนชื่อแท็บ ลบแถวที่ 1 หรือสลับลำดับคอลัมน์** ระบบอ่านข้อมูลตามตำแหน่งคอลัมน์ เพิ่มคอลัมน์ของตัวเองทางขวาสุดได้

## การติดตั้งระบบใหม่

ใช้เมื่อย้ายระบบไปบัญชีอื่น หรือติดตั้งให้หน่วยงานอื่น ใช้บัญชี Gmail เดียวกันตลอดขั้นตอนที่ 1–3

**1. Google Sheet และ Apps Script**
1. สร้าง Google Sheet ใหม่ › **ส่วนขยาย › Apps Script**
2. วางโค้ดจาก `Code.gs` ทับโค้ดเดิม › กด 💾
3. เลือกฟังก์ชัน **setup** › **Run** › อนุญาตสิทธิ์
   (ถ้าขึ้น "Google hasn't verified this app" กด **Advanced › Go to … (unsafe)** › ติ๊ก **Select all** › **Continue**)

**2. Google Cloud: สร้าง Client ID**
1. https://console.cloud.google.com › สร้างโปรเจกต์ใหม่
2. **Google Auth Platform** › **Get started** › Audience: **External**
3. เมนู **Audience** › **Publish app** (ไม่อย่างนั้นจะเข้าสู่ระบบได้แค่เจ้าของ)
4. เมนู **Clients** › **Create client** › Web application
   **Authorized JavaScript origins:** `https://ชื่อผู้ใช้github.github.io` (ตัวพิมพ์เล็ก ไม่มี / ท้าย)
5. คัดลอก Client ID ไปใส่ใน `Code.gs` บรรทัด `const CLIENT_ID` › กด 💾

**3. Deploy Apps Script**
**Deploy › New deployment** › Web app › Execute as: **Me** · Who has access: **Anyone** › คัดลอกลิงก์ที่ลงท้ายด้วย `/exec`

**4. config.js**
```js
window.API_URL = "ลิงก์ /exec จากขั้นตอนที่ 3";
window.CLIENT_ID = "Client ID จากขั้นตอนที่ 2";
```

**5. GitHub Pages**
สร้าง repository แบบ **Public** › อัปโหลด `index.html` และ `config.js` › **Settings › Pages** › Branch: **main** / **(root)** › **Save**

## การแก้ไขและดูแลระบบ

### แก้ Code.gs
หลังแก้และกด 💾 แล้ว ต้อง deploy เวอร์ชันใหม่โดย**ใช้ลิงก์เดิม**:
**Deploy › Manage deployments** › ดินสอ ✏️ › Version: **New version** › **Deploy**

⚠️ อย่ากด **New deployment** เพราะจะได้ลิงก์ใหม่ และต้องแก้ `config.js` ตาม

### แก้หน้าเว็บ
repository นี้ › **＋ › Upload files** › ลาก `index.html` ตัวใหม่มาวาง › **Commit changes** แล้วรอ 1–2 นาที
ถ้ายังเห็นของเดิม กด **Ctrl+Shift+R** (Mac: **Cmd+Shift+R**)

### เพิ่มหรือเปลี่ยนชื่อทีม
แก้ `const TEAMS` ให้ตรงกันทั้ง 2 ไฟล์ แล้วอัปเดตตามสองหัวข้อข้างบน
- `Code.gs`
- `index.html`

ทีมปัจจุบัน: ศูนย์สกัดฯ · PGx Service · NIPT · ผูกพันธุ์ · Pathogen · PGx-LRs · บริหารฯ

### สำรองข้อมูล
Google Sheet เก็บประวัติเวอร์ชันให้อัตโนมัติ (**ไฟล์ › ประวัติเวอร์ชัน**) แนะนำให้ **ไฟล์ › ทำสำเนา** เก็บไว้ทุกสิ้นปีด้วย

### เปลี่ยนผู้ดูแลหลัก
เจ้าของ Google Sheet และ Apps Script คือผู้ดูแลหลัก ถ้าเปลี่ยนผู้รับผิดชอบ ให้เพิ่มคนใหม่เป็นผู้ดูแลในแท็บตั้งค่า หรือติดตั้งใหม่ด้วยบัญชีของคนนั้นตาม [การติดตั้งระบบใหม่](#การติดตั้งระบบใหม่)
